# Data-package checklist for the submission

| Item | Prepared status |
|---|---|
| Separate local data package; originals preserved | Complete |
| Deidentified trial and reversal tables | Complete for the selected CSF/PSF data |
| Primary CSF points and thresholds | Complete; exact raw-data reconstruction |
| Saved PSF distributions, exclusions and uncertainty summaries | Complete; all original saved rows retained |
| Saved resampled CSF inputs and hashes | Complete; preserved because historical seeds/linkage are unresolved |
| README, data dictionary, provenance, manifests and runnable checks | Complete |
| Analysis environment | Validation environment recorded; historical environment unresolved |
| Calibration | Recorded settings plus unassigned candidate datasets; author confirmation needed |
| Exact historical bootstrap regeneration | Unresolved; detailed comparison provided |
| Final independent f_n/f_r fits and complete paper/SI reproduction | Diagnostic replay provided; final scientific reconciliation and remaining figures needed |
| Data/code licenses and sharing-consent confirmation | Pending author decisions |
| Citation metadata and availability wording | Draft prepared; DOI/contact/release details pending |
| Public repository deposit | Not performed |

PNAS uses public-repository availability and a submission-stage sharing plan; the table layout here is a documented implementation choice. Direct retrieval of the two official author pages returned HTTP 403 during preparation. The supplied checklist and the [PNAS 2025 Overleaf template](https://www.overleaf.com/latex/templates/template-for-preparing-your-research-report-submission-to-pnas-using-overleaf/fzcbzjvpvnxn) support this approach. Recheck [Submitting Your Manuscript](https://www.pnas.org/author-center/submitting-your-manuscript) and [Editorial and Journal Policies](https://www.pnas.org/author-center/editorial-and-journal-policies) before submission.

This data checklist does not mark unrelated manuscript, author-approval, funding, reviewer-nomination, ethics, or portal fields complete.
