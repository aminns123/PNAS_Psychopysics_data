# Data, materials and software availability

## Wording for the existing empirical archive

Deidentified trial-level psychophysical data, derived contrast sensitivity functions and preferred spatial frequencies, saved resampling inputs and fit distributions, and associated empirical analysis code are available in Zenodo, version v1.0.0 (https://doi.org/10.5281/zenodo.22644071). The maintained repository is https://github.com/aminns123/PNAS_Psychopysics_data. The archive documents verification of the primary CSFs and saved PSF summaries and the remaining limitations of historical resampling reproducibility.

This wording describes the empirical CSF/PSF materials. The DOI names the existing v1.0.0 snapshot. A later GitHub revision does not change the contents named by that DOI. If a subsequent release is archived, cite its actual version DOI when those later files are used; do not silently relabel the earlier archive.

The concept DOI, https://doi.org/10.5281/zenodo.22644070, groups the versions. Prefer the specific version DOI when identifying the exact deposited files supporting a result. Dataset citation metadata are in [CITATION.cff](CITATION.cff).

The supplied DOI is for the archive, not for a bioRxiv preprint. Add a preprint link only after its actual identifier is available. This repository update does not modify manuscripts already submitted to a journal or preprint service.
